Abstract

The project titled Morrow is a personal finance management web application designed to help users manage income, expenditure, budgets, and financial reports efficiently. The system provides a clean dashboard where users can add, track, and categorize transactions while maintaining visibility into their monthly financial health. By combining local data persistence, modular React components, and a lightweight Express API, the project offers a practical and responsive user experience for day-to-day financial planning.

Morrow allows users to monitor income and expenses, review budget progress, import CSV data, generate category-wise reports, and manage multiple financial workspaces. The system is built using React, Vite, and Express.js, making it efficient, scalable, and easy to extend for future enhancements such as authentication, cloud storage, and advanced forecasting.

Keywords

Personal Finance, Budget Tracking, Expense Management, React, Vite, Express, CSV Import, Financial Dashboard

Introduction

In the modern digital era, personal financial management has become an essential part of everyday life. Many users struggle to keep track of income, recurring expenses, and savings goals because traditional methods such as paper notes or spreadsheets are often inconvenient and difficult to analyze. A personal finance application helps individuals understand their spending habits, reduce unnecessary costs, and make better financial decisions.

The Morrow application addresses this challenge by providing a user-friendly finance workspace for tracking transactions, setting budgets, and reviewing financial insights. It brings together dashboards, monthly summaries, budget analysis, and reporting tools into a single platform.

Problem Statement

Many individuals do not have an organized system to monitor their financial activities. They often lose track of where money is being spent, fail to compare expenses against their budget, and find it difficult to identify trends over time. Without a digital management solution, financial planning becomes time-consuming and error-prone.

This project aims to solve that issue by offering an easy-to-use finance dashboard that helps users record transactions, understand their cash flow, and manage spending across different categories and accounts.

Objectives

  • To develop a responsive personal finance management system.
  • To allow users to record and manage income and expense transactions.
  • To provide budget monitoring and monthly financial summaries.
  • To generate category-wise spending and financial reports.
  • To support CSV import/export for data management.
  • To create a modular architecture for easy future enhancement.

System Overview

Morrow is implemented as a web-based application that combines a React frontend with an Express backend. The frontend is responsible for presenting pages such as Overview, Transactions, Budgets, Reports, Accounts, Import CSV, and Settings. The backend stores financial data in JSON files and exposes endpoints for transactions, budgets, and app state. A local browser storage fallback is also included so that the app remains functional even when the API is unavailable.

Features of the Application

  • Overview Dashboard: Displays total income, total expenses, balance, and monthly insights.
  • Transactions Management: Allows adding, searching, filtering, and deleting income and expense records.
  • Budget Tracking: Enables users to set spending limits by category and monitor remaining amounts.
  • Reports: Provides spending breakdowns and monthly trends for better analysis.
  • Accounts: Offers account-level financial summaries and balances.
  • CSV Import and Export: Supports importing historical financial data and exporting transaction data.
  • Multi-Workspace Support: Lets users manage more than one finance workspace or account space.
  • Custom Themes: Allows users to change interface themes and accent colors.

Technologies Used

  • Frontend: React.js, Vite, React Router DOM
  • Backend: Node.js, Express.js
  • Styling: CSS and component-based design
  • State Management: Local state with browser-local persistence and API synchronization
  • Data Storage: JSON file-based persistence
  • Libraries: Lucide icons, custom formatting utilities

System Architecture

The application architecture follows a modular three-layer structure. The presentation layer is built with React and contains pages and reusable UI components. The application logic layer is implemented through custom hooks and helper functions that manage state, calculations, and persistence. The data layer uses an Express API and JSON-based storage for saving and retrieving records.

This architecture improves maintainability because each feature is separated into logically organized folders such as pages, hooks, services, styles, and data. It also supports easy updating of functionality without disrupting the rest of the application.

Implementation Details

The project was implemented in a modular structure using React components. The main application shell is defined in FinanceApp.jsx, where navigation, route handling, workspace selection, theme configuration, and transaction export functions are managed. Each financial screen is separated into its own page component to keep the application scalable and organized.

The data logic is handled by the custom hook useFinanceData.js, which manages transactions, budgets, and local storage operations. Budget calculations and financial summaries are derived in real time to provide instant feedback to the user. The API included in the server layer exposes routes for retrieving and updating state, transactions, and budget information.

The project also supports CSV import workflows, category-based reporting, and theme customization, which makes the app useful for both personal tracking and practical financial overview.

Modules / Screens

  • Overview Page: Displays summary cards and key financial insights.
  • Transactions Page: Handles adding, editing, filtering, and deleting records.
  • Budgets Page: Tracks monthly limits by category and remaining values.
  • Reports Page: Shows category breakdown and spending trends.
  • Accounts Page: Shows balances and account-wise financial insights.
  • Import Page: Allows CSV data upload and preview before saving.
  • Settings Page: Supports theme selection and customization preferences.

Testing and Validation

The application was validated through functional testing of the core workflows, including transaction creation, budget updates, CSV import, and report generation. The design was checked for responsiveness and usability to ensure the interface works well on both desktop and mobile devices.

Testing confirmed that the app can efficiently update summaries in real time, store data locally, and maintain clear financial visibility for the user.

Advantages

  • Simple and intuitive user interface.
  • Real-time financial summary updates.
  • Budget and transaction tracking in one place.
  • Responsive design and multi-workspace support.
  • Easy data export and import features.

Limitations and Future Scope

At present, the system is designed as a personal finance workspace and does not include advanced authentication, database integration, or cloud synchronization. However, the architecture is modular and can be extended to support secure login, multi-user dashboards, predictive analytics, recurring expenses, and AI-based financial recommendations in future versions.

Conclusion

The Morrow project successfully demonstrates the development of a practical personal finance management system using modern web technologies. It combines financial tracking, budgeting, reporting, and data import/export into a single platform that is responsive, modular, and user-friendly. The project meets the essential objectives of personal finance management and provides a strong foundation for future expansion into a more advanced financial planning tool.
