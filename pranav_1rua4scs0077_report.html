Abstract

Morrow is a personal finance management application designed to help users manage income, expenses, budgets, and financial reports. It offers a clean dashboard for tracking transactions, analyzing cash flow, and maintaining better financial discipline.

Introduction

Personal finance management is essential for controlling daily spending and planning long-term goals. This project provides a simple interface for tracking financial activity and understanding monthly behavior.

Objectives

  • Track income and expenses.
  • Set and monitor category budgets.
  • Generate spending reports.
  • Import and export financial data.
  • Provide a responsive dashboard.

Technologies Used

  • React
  • Vite
  • Express.js
  • CSS
  • JSON-based persistence

Features

  • Overview dashboard
  • Transactions management
  • Budget tracking
  • Reports
  • Accounts
  • CSV import/export
  • Theme customization

Conclusion

The Morrow application successfully demonstrates how a personal finance tracker can help users monitor spending, manage budgets, and analyze financial data more effectively.
